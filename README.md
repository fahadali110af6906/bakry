# 🥐 Le Petit Délice - Artisanal Bakery & Patisserie Web App

A high-performance, mobile-first web application designed for artisanal bakeries. It seamlessly bridges the customer ordering experience and business owner kitchen management.

---

## ✨ Features

### 🛍️ Customer Experience
- **Artisan Catalog**: Filter by dietary preferences (Vegetarian, Vegan, Gluten-Free, High Protein) and categories (Breads, Viennoiserie, Savory, Specialty Coffee).
- **Interactive 3D Cake Studio**: Fully customizable tiered celebration cakes with real-time price estimation, flavor tiers, frosting textures, and custom piping messages.
- **Smart Cart & Checkout**: Live order summary with pickup time slots and special baking instructions.
- **5-Stage Order Tracker**: Real-time order progress from kneading and oven baking to packaging and ready for pickup.
- **Mobile-First Design**: Optimized for Android and mobile browsers with native-style status bar, header, and bottom navigation.

### 📊 Business Owner Admin Suite
- **Live Sales & KPI Metrics**: Daily revenue, order counts, average ticket size, and top-selling artisan items.
- **Live Kitchen Queue**: Real-time kitchen management with order status toggling (Baking, Packaging, Completed).
- **Batch Inventory Management**: Daily fresh batch limits and instant inventory status toggles.

---

## 🛠️ Tech Stack

- **Framework**: React 18 (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Visuals & Charts**: Recharts & Canvas Confetti
- **Deployment Ready**: Vercel & Netlify configured

---

## 🚀 Getting Started

### Local Development

1. Clone or download the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

---

## 🌐 Deploy to Vercel

1. Push this repository to **GitHub**.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Vercel will automatically detect **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**!
